What changes the score
Paid

Collected amount

Add the paid amount from every enrollment. Paid money does not remove points.

− {{ pendingMax }}

Pending penalty

Pending ÷ (Paid + Pending) × {{ pendingMax }}.

All pending removes {{ pendingMax }}. Nothing pending removes 0.

− {{ lateMax }}

Late penalty

A late installment still has a balance and its due date has passed.

  • {{ lateInstallmentPoints }} points for each late installment
  • {{ lateDayPoints }} point for each late day
  • Only the first {{ lateDaysCap }} late days of each installment count
  • This penalty stops at {{ lateMax }}
