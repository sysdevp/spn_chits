SPN Chits – 44 Point Change Guide

What was changed for each point, where to find it, and how to use it. Menu paths are from the left sidebar; URLs are relative to /admin-panel/.
Before you start
  • After a deploy, log out and log in again so the new menus and permissions are loaded.
  • New database tables and columns (SPN groups, KYC verification, employee advance, payment chit-admin stage) are created automatically the first time the page is opened. No manual SQL is needed.
  • New menus follow the existing security permissions. If a user cannot see a menu, tick it under HR → Security Permissions (see point 36).

Admin Dashboard (points 1 – 13, 43)

Every card on the MD / admin dashboard is now clickable. Each one opens a full overview page at hub/<section> with KPI cards, a branch-wise breakdown, charts and a detail table. Each overview page has a branch filter and Excel/CSV export.

1) Today Collection – click shows data

today collection if i click not showing data
Where: Dashboard → Today Collection card (URL hub/today-collection).
How it works: Shows today's receipts with totals by branch, by employee and by payment mode, plus a chart and the full receipt list.

2) Sales Target – overview, top 3 branch-wise and employee-wise

sales target > if i click not opening ... top 3 sales branchwise and employee wise
Where: Dashboard → Sales Target card or the Target panel's "View Details" (hub/sales).
How it works: Target vs achieved for the month, the top 3 branches and top 3 employees by sales, a branch-wise chart and an employee-wise table.

3) Today Enrollment – full details

Where: Dashboard → Today Enrollment card (hub/today-enrollment).
How it works: Lists every chit enrolled today: customer, scheme, slab, branch, employee and amount, with branch-wise totals.

4) Pending Collection and 5) Overdue Collection

Where: Dashboard → Pending Collection (hub/pending-collection) and Overdue Collection (hub/overdue-collection).
How it works: Shows the pending (this month) or overdue (past months) amount per branch, then per customer with due number and amount, with a chart.

6) All dashboard cards open a new overview page

How it works: Click any top card (collection, sales, chits, enrollment, pending, overdue, attendance). It opens a new page with branch-wise data and charts. Use the browser Back button or the sidebar to return.

7) Top 3 Employees and Branches – why they are best

Where: The "Top Employees" and "Top Branches" boards → Full Overview (hub/top-performers).
How it works: Ranks branches and employees by business (collection plus new enrollments) and by target achievement %, showing the numbers behind each rank.

8) Live Tracking and Today Attendance – present / absent count

Where: Dashboard → Attendance card (hub/attendance). "View Full Map" opens live tracking.
How it works: Shows present and absent counts, branch-wise. Clicking opens the full employee list with punch in and punch out times.

9) Employee birthdays – today and this month

Where: Dashboard → Birthdays tile (hub/birthdays).
How it works: Two lists: employees with a birthday today and this month, with their branch.

10) Today Task and Today Target

Where: Dashboard → Today Tasks / Today Target tiles (hub/tasks-targets).
How it works: Shows tasks assigned today (open and completed) and each employee's target vs achieved, branch-wise.

11) Today Expenses – fixed

Where: Dashboard → Expenses panel → View All (hub/expenses).
How it works: Shows only today's expense and petty-cash entries, with the head, branch and amount, and a branch-wise total.

12) Recent Collection no longer goes to Settlement

How it works: "Recent Collections" → View All now opens the receipts overview (hub/today-collection), not the settlement screen.

13) Settlement Approvals on the dashboard

Where: Dashboard → Settlement Approvals panel. "View All" opens hub/settlement-approvals; "Approve Settlements" opens the settlement report.
How it works: Lists pending cash settlements with branch, employee and amount. Approve them from the settlement screen.

43) Corporate Admin Panel

Where: Dashboard header → Corporate button (hub/corporate). The existing dashboard is unchanged.
How it works: A company-level panel covering all branches: collection, enrollment, outstanding, staff and approvals, with a branch comparison chart. Click a branch to open its own overview (branch-overview/<id>).

Reports (points 17 – 20, 31 – 35, 38)

17) Eligibility Approval – overall branch option

Where: SPN Chit Management → SPN Eligibility Approval (commitment-eligibility-approval).
How it works: The branch dropdown has All Branches, which shows every branch's eligible customers in one list.

18) Cancelled Customers Report – scheme and slab filter only

Where: Reports → Cancelled Customers Report (cancel-customer-report).
How it works: The group filter was removed. Pick a Scheme, then optionally a Slab (the slab list follows the scheme), then Search.

19) Customer Category report (Excellent / Good / Bad)

Where: SPN My Customers → Customer Category (Excellent / Good / Bad) (customer-category-report).
How it works: This is a separate menu, not the formula screen. Filter by branch (All Branches or one), scheme and grade. KPI cards show the count per grade, and the table lists each customer with score, grade, scheme, paid and pending. Export to CSV. The grade rules are still set in Settings → Customer Score Rules.

20) Chit Enrollment Report – scheme dropdown fixed, chit based

Where: Reports → Chit Enrollment Report (commitment-report).
How it works: The report is now based on commitment chits, not groups. Filters: branch (optional, All Branches), scheme (now loads correctly), slab, and from/to enrollment date. A Scheme column was added.

31) and 35) "Commitment" removed from report names

How it works: Report menu items and page titles no longer use the word "Commitment". For example, "Commitment Receipt Report" is now "Receipt Report (New / Old)" and "Commitment Report" is now "Chit Enrollment Report". Only the visible names changed; the URLs are unchanged.

32) Old / New customer filter

Where: Reports → Receipt Report (New / Old).
How it works: A new New / Old Customer filter and column. Old means the customer has paid at least the first full installment (scheme monthly due). New means they are still in the first due.

33) This Month Unpaid – due no and running month

Where: Reports → This Month Unpaid (this-month-unpaid-report).
How it works: The running month now comes from the same installment number as the due number, so both columns always show the same current due.

34) Other Charges report – real charge name

Where: Receipts & Payments → Other Charges Receipt (other-receipt-charges-report).
How it works: A new Charge Name column (also in the PDF) shows the actual charge from the Charge Type master. Only receipts with no charge type show "Registration Fee (RF)". You can filter by charge type. "Group Name" is now "Chit / Scheme".

38) Prized Payment – this chit pending vs old chit pending

Where: Payments → Prized Payment (payment-priced).
How it works: The single "Total pending" figure is replaced by two figures: This chit pending (only the chit being paid) and Old chit pending (the customer's other chits). This is shown in all four places on the screen.

Customers, KYC and Chits (points 22 – 25)

22) Family Code Master checked

Where: SPN My Customers → Family Code Master (view-family-code).
How it works: The list shows branch, family code and a new Members count. Use the eye icon to see members and the edit icon to update.

23) Profile – Aadhaar front and back, PAN and multiple documents

Where: SPN My Customers → Profile Creation → Add Customer (and Update Customer), in the KYC Documents section.
How it works:
  • There are four upload slots: Aadhaar Front, Aadhaar Back, PAN Card and Other Documents. Other Documents accepts several files at once.
  • Each file uploads as soon as it is chosen (maximum 5 MB; image or PDF). Remove one with the × button.
  • On Add Customer, the documents are saved automatically after the customer is saved.
  • On Update Customer, press Save Documents.
  • Saved documents appear in KYC Documents & Approval (point 25).

24) Chit section moved to a separate page

How it works: The chit block is no longer inside customer creation. After saving a new customer, the system asks "Add a chit for this customer now?":
  • Yes opens SPN My Customers → Add Chit (add-commitment-chit).
  • No returns to the customer list.

25) KYC Documents – customer name, chit details and approval

Where: SPN My Customers → KYC Documents & Approval (view-documents).
How it works:
  • Filter by branch (or All Branches) and by KYC status (Pending, Approved or Rejected).
  • The list shows the full customer name, code, mobile, the chit details (scheme, slab and AR no) and a KYC status badge.
  • Click the eye icon to open the documents. The pop-up shows the customer details, a chit table and every uploaded file.
  • Enter remarks if needed, then press Approve KYC or Reject. Remarks are required when rejecting.
  • The approver and the date are recorded.

SPN Group Formation (points 28, 29)

28) SPN New Group

Where: SPN Chit Management → SPN New Group (spn-new-group).
How to use:
  • Choose a Branch (or All Branches for a cross-branch group), a Scheme, a Slab and a Due No. The due-number list shows how many free chits each due has.
  • Choose a mode:
    • Auto: the system picks the first free chits on that due number, up to the maximum.
    • Manual: tick the customers yourself.
  • Enter a Group Name, or leave it blank for an automatic name such as 50000-10M-D3-G1. Then press Create Group.
Rules enforced:
  • The maximum number of members equals the scheme's number of months. For example, a 50,000 / 10-month scheme allows exactly 10 members, and the counter blocks more.
  • All members must be on the same due number.
  • A chit can belong to only one group.

29) Group View

Where: SPN Chit Management → Group View (spn-group-view).
How it works:
  • Filter by branch, scheme, slab, due no or group name.
  • KPI cards show the total groups, full groups, open seats and members.
  • Each group row shows a fill bar (for example 7 / 10). Expand a row to see its members with paid and pending amounts.
  • From the expanded row you can Add Member (same due, if seats are free), Remove a member or Delete the group.
  • Export to CSV.

Payments and Approval Process (points 37, 39)

37) Commitment Payment renamed to Prized Payment

Where: Receipts & Payments → Prized Payment, and Payments → Prized Payment.
How it works: Every "Commitment Payment" title, button and message now reads "Prized Payment" (Add / View / Delete Prized Payment). Only the names changed; the payment logic is the same.

39) Payment request process – Branch → Chit Admin → Final Approval

Branch request → Field verification → Chit Admin check → Final (MD/Admin) approval → Payment release
  • 1. Branch request: the branch raises the request in Payments → Prized Payment, Final Closed Payment or Refund Payment. Status: Field visit.
  • 2. Field verification: the field employee submits camera photos, the home pin and the collection pin from the mobile app. Status: Chit admin.
  • 3. Chit Admin: opens Payments → Pending Approvals, checks the photos and pins, enters remarks, then presses Verify & Forward or Reject.
  • 4. Final approval: the admin/MD sees the forwarded row with the chit admin's remarks and presses Final Approve or Reject. Status: Processed or Cancelled.
  • The Pending Approvals page shows counts for each stage: Waiting field visit, Waiting chit admin, Ready for final approval, Approved and Rejected.
  • Requests that were already at "Pending admin" before this change can still be approved directly.
  • Receipts, refunds and ledgers are unchanged.

HR – Permissions, Advance, Attendance (points 36, 40, 41)

36) Security permissions for all current menus

Where: HR → Security Permissions (add-permission).
How it works: The permission tree now matches the current side menu: SPN My Customers, SPN Chit Management, Receipts & Payments, Payments, HR, SPN Target / Task, SPN Account Management, Reports and the rest. Every new screen in this guide is included. Select a role, tick View / Add / Edit / Delete for each screen, and save. The user sees the changes after logging in again.

40) Employee Advance / Loan menu

Where: HR → Employee Advance / Loan (employee-advance). Employee Salary is unchanged.
How to use:
  • Select a branch and then an employee. Choose the type (Advance or Loan) and enter the amount and number of months; the EMI is calculated automatically. Enter the date and reason, then Save.
  • The list shows KPI totals and filters by branch, type and status.
  • Actions move a request through the stages: Approve or Reject, then Mark Paid once the money is given, then Mark Recovered once it is fully repaid.

41) Attendance without the map

Where: HR → Attendance (In / Out) (view-employee-attendance). The map is now only in HR → Live Tracking & Punch Map.
How it works:
  • Filter by branch and employee, then choose a view: Day wise (one date), Month wise (one month) or From – To (date range).
  • The table shows each employee's punch in and punch out time and branch.
  • KPI cards show employees, punched in, punched out and outside office.
  • Excel exports the list. "Open Live Map" goes to the tracking screen.
Technical note: The frontend production (AOT) build and the type check pass, and all changed PHP files pass syntax checks. New tables (spn_groups, spn_group_members) and new columns (KYC verification on documents, chit-admin stage on payment_desk_requests) are added automatically on first use.
